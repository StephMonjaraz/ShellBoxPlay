# CONTRIBUTING.md

¡Gracias por tu interés en contribuir a **ShellBoxPlay**!

## 🙋‍♀️ Contribuciones bienvenidas
Este proyecto fue desarrollado por una sola persona, pero puedes:
- Sugerir mejoras
- Reportar errores
- Proponer nuevos comandos o juegos

## 🛠️ Requisitos
- Conocimiento básico de Bash
- Familiaridad con sistemas GNU/Linux
- Buenas prácticas en Git y GitHub

## 🔃 Clonar y configurar
```bash
git clone https://github.com/StephMonjaraz/ShellBoxPlay.git
cd ShellBoxPlay
chmod +x *.sh comandos/*.sh juegos/*.sh reproductor/*.sh
```

## 📏 Convenciones
- Usa nombres descriptivos para tus funciones y scripts.
- Escribe comentarios si el código puede resultar complejo.
- Sigue la estructura modular del proyecto.

## 📝 Commits
Formato sugerido:
```
[NOMBRE][TIPO][DESCRIPCIÓN]
Ejemplo: [STEPHANIE][ADD][Nuevo comando infosis]
```

## 📬 Issues y Pull Requests
1. Abre un *issue* explicando el problema o mejora.
2. Espera retroalimentación.
3. Haz tu fork y pull request con claridad en el cambio.

## 🧪 Pruebas
- Ejecuta `main.sh`
- Verifica comandos nuevos con casos básicos.
- Asegúrate de que no se rompa el flujo actual del sistema.
